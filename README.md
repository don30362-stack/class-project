# Home Fitness

以 PHP、MariaDB、Bootstrap 製作的居家健身器材購物網站，包含商品分類、商品詳細頁、購物車、結帳及會員功能。

## 快速啟動

1. 安裝 PHP 8.2+ 與 MySQL／MariaDB。
2. 匯入 `database/expstore.sample.sql`。
3. 依本機環境調整 `config/conn_db.php`。
4. 在專案根目錄執行 `php -S 127.0.0.1:8000`。
5. 開啟 `http://127.0.0.1:8000/`。

完整環境需求與資料內容界線請參考 [本機啟動方式](docs/setup.md)。專案目錄說明位於 [目錄結構](docs/structure.md)，前端套件版本位於 [前端依賴](docs/dependencies.md)。
